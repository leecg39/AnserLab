# AnserLab

이 저장소는 아래 순서로 일합니다. 한 줄 요약은 **PRD 뼈대 → Task 1 → 워크플로우**입니다.

| 단계 | 하는 일 |
|---|---|
| 준비 | GitHub 저장소 연결 |
| 설계 | `docs/PRD.md` 작성, task끼리 건드리는 파일·폴더가 겹치지 않게 나눔 |
| 시범 | Task 1을 세부 항목별 PR로 직접 올림 |
| 위임 | Task 2부터 "WORKFLOW.md대로 해"로 AI에게 맡김 |
| 보완 | 떠오르는 수정 사항은 GitHub 이슈로 남김(휴대폰 GitHub 앱 가능) |
